# Clipvault

[English](README.en.md) · [Русский](README.md)

Умный менеджер буфера обмена для Windows с приватностью по умолчанию — замена Ditto и истории `Win+V`:
бесконечная история с мгновенным нечётким поиском, дедупликация и **шифрование на диске**. Всё хранится
локально, без облака, синхронизации и телеметрии.

![История буфера: список записей и предпросмотр](docs/screenshots/01-history.png)

*Все скриншоты сделаны на выдуманных данных (`Clipvault.exe --demo`) — настоящих записей буфера на них нет.*

## Чем отличается

- **Содержимое на диске зашифровано целиком** — не только «пароль на файл»: ни данные, ни метаданные, ни
  поисковый индекс, ни временные файлы не лежат открытым текстом (см. [модель угроз](#приватность-и-модель-угроз)).
- **Никакого хука клавиатуры.** Горячая клавиша — `RegisterHotKey`, буфер — `AddClipboardFormatListener`.
- **Вставка без сюрпризов:** Clipvault возвращает фокус окну, из которого вы вызвали список, и нажимает в нём
  `Ctrl+V`. Если окно запущено от администратора, Windows этого не позволит (UIPI) — программа так и скажет.

## Возможности (версия 0.1.0)

- **Что запоминает:** текст, форматированный текст (HTML/RTF), изображения, списки файлов (`CF_HDROP`), цвета
  (`#HEX`, `rgb()`, `hsl()` — с цветным превью), ссылки и пути; для каждой записи — программа, заголовок окна
  и время.
- **Дедупликация.** BLAKE3 от нормализованного содержимого; повтор поднимает запись наверх и увеличивает
  счётчик копирований, а не создаёт копию.
- **Окно по `Ctrl+Alt+V`** (сочетание настраивается; `Win+V` зарезервировано Windows): мгновенный нечёткий
  поиск по мере ввода, фильтры по типу, приложению и дате, предпросмотр, вставка клавишей `Enter` или
  цифрой `1–9`, закрепление (`Ctrl+P`), удаление (`Ctrl+D`), «Очистить всё».
- **Лимиты:** размер записи, срок хранения, число записей (закреплённые лимитами не затрагиваются).
- **Пауза записи и «режим инкогнито»** — из окна и из меню значка в трее.
- **Окно администратора.** Обычная копия не может вставлять в окна «от администратора»; для них —
  `Clipvault.exe --admin` (кнопка в «Настройках», один запрос UAC, своё сочетание `Ctrl+Alt+Shift+V`).
  Она только вставляет и ничего не записывает; основная копия остаётся без повышения прав.
- **Установщик без прав администратора**, автообновление с проверкой SHA-256, журнал и отчёты о сбое
  без содержимого буфера, демо-режим, интерфейс на русском и английском.
- **`clipvault-cli`:** `list`, `search`, `get <id>`, `purge`.

## Установка

Скачайте `Clipvault-Setup.exe` со страницы [Releases](https://github.com/ahsoggg-creator/clipvault/releases/latest)
и запустите. Права администратора не нужны — программа ставится в `%LOCALAPPDATA%\Programs\Clipvault`,
добавляет ярлык в меню «Пуск» (по желанию — на рабочий стол) и запись в «Приложения и возможности».
Запуск при входе в Windows — по галочке (по умолчанию выключен).

Есть и переносная версия — просто `Clipvault.exe` (тот же файл), её можно установить позже из «Настроек».
Без окна: `Clipvault-Setup.exe --install --silent`, `Clipvault.exe --uninstall --silent`.
`Clipvault.exe --background` запускает программу в трее, не показывая окно.

Значок в области уведомлений (возможно, под «^»): левый клик — окно, правый — меню (пауза, инкогнито,
настройки, выход).

### Подпись кода и SmartScreen

Исполняемые файлы релизов **не подписаны** (GitHub Actions не имеет закрытого ключа), поэтому Windows может
показать «неизвестный издатель». Проверяйте контрольные суммы из `SHA256SUMS.txt`:

```powershell
Get-FileHash .\Clipvault-Setup.exe -Algorithm SHA256
```

Автор может подписывать сборки самоподписанным сертификатом локально: `scripts\make_cert.ps1` создаёт
сертификат (закрытый ключ остаётся только в хранилище сертификатов пользователя, файлы `*.pfx` исключены из
git), `scripts\release.ps1` подпишет файлы, если сертификат есть, а `scripts\trust_cert.ps1` позволит
доверять ему на своём компьютере. Самоподписанный сертификат подтверждает «подписано тем же автором», но
не убирает предупреждение SmartScreen сам по себе.

## Приватность и модель угроз

Clipvault ничего никуда не отправляет, кроме проверки новой версии на `api.github.com` раз в сутки
(отключается в «Настройках»; `Clipvault.exe --update` делает то же вручную). Нет синхронизации, облака, телеметрии.

**Как устроено хранилище.** Папка `%APPDATA%\Clipvault` (или `CLIPVAULT_DATA_DIR`):

| Файл | Что внутри |
| --- | --- |
| `vault.bin` | журнал кадров XChaCha20-Poly1305: записи, их метаданные, картинки и HTML/RTF — всё внутри зашифрованных кадров |
| `vault.key` | 32-байтовый ключ, обёрнутый DPAPI (`CryptProtectData`) для вашей учётной записи Windows |
| `vault.lock` | пустой файл-замок (GUI и `clipvault-cli` работают с одним хранилищем) |
| `settings.json` | настройки: язык, сочетание клавиш, лимиты (содержимого нет) |
| `logs\` | журнал и отчёты о сбое (содержимого буфера нет) |

SQLite и SQLCipher не используются: собственный формат журнала не создаёт WAL и временных файлов с открытым
текстом, а поиск идёт по индексу, который строится **в памяти** при запуске. Пересборка файла
(при удалении записи и «Очистить всё») пишется в новый зашифрованный файл и подменяет прежний.

**От чего защищает:**

- от копирования или кражи файлов данных (резервная копия, чужой компьютер, другая учётная запись Windows,
  флешка): без ключа вашей учётной записи Windows прочитать их нельзя;
- от того, что содержимое окажется в облачном бэкапе/индексаторе папки `AppData` открытым текстом;
- от подмены и перестановки кадров внутри файла (в AAD входят поколение файла и номер кадра).

**От чего не защищает:**

- от программы, запущенной **под вашей учётной записью**: она может сама вызвать DPAPI и получить ключ —
  как у любого менеджера без мастер-пароля;
- от администратора / вредоносной программы с доступом к памяти процесса (ключ и расшифрованные записи
  находятся в памяти Clipvault; возможны файл подкачки и гибернации), от кейлоггеров и снимков экрана;
- от самого буфера обмена: пока вы не вставили и не заменили содержимое, оно открыто лежит в буфере Windows
  и доступно любой программе;
- от анализа метаданных: размер и время изменения `vault.bin`, существование файлов;
- от усечения хвоста журнала (обрыв последних кадров не обнаруживается);
- от остатков на SSD: после удаления файл пересобирается, но старые блоки с шифртекстом могут пережить
  перезапись (без ключа они бесполезны).

Автофильтр секретов (пароли, ключи, сид-фразы) в этой версии **отсутствует**: всё, что вы скопировали,
попадает в историю. Если копируете пароль, включите «режим инкогнито» или паузу.

## Диагностика

- `%APPDATA%\Clipvault\logs\clipvault.log` — запуск и остановка, проблемы с обновлением и хранилищем; ротация
  при 512 КБ;
- `%APPDATA%\Clipvault\logs\crashes\crash-<время>.txt` — создаётся при сбое: версия, **место** паники, стек
  вызовов и хвост журнала. Текст самой паники в отчёт намеренно не пишется: сообщения стандартной библиотеки
  могут цитировать обрабатываемые данные. При следующем запуске Clipvault сообщит, где лежит отчёт.

В журнал и отчёты никогда не попадает содержимое буфера — только типы и счётчики. «Настройки» → «Диагностика»
открывают эту папку или копируют диагностический текст (версия, число записей по типам, хвост журнала).

## Сборка

Нужен Rust (stable, edition 2024) и MSVC. Только Windows.

```powershell
cargo build --release            # target\release\Clipvault.exe и clipvault-cli.exe
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
powershell -ExecutionPolicy Bypass -File scripts\e2e.ps1     # проверка на живом рабочем столе: буфер, сочетание, вставка, установщик
powershell -ExecutionPolicy Bypass -File scripts\release.ps1 # проверки, сборка, (подпись), артефакты в dist\
```

Структура:

- `crates/core` — вся логика без интерфейса: зашифрованное хранилище, история, дедупликация, поиск,
  классификация, форматы буфера, настройки, таблица локализации; тесты;
- `crates/app` — GUI на egui, окно-слушатель Windows (буфер, сочетание, трей), вставка, установщик,
  автообновление, диагностика, демо-режим;
- `crates/cli` — `clipvault-cli list | search | get | purge`.

Тот же exe работает как установщик, если называется `Clipvault-Setup.exe` (или запущен с `--install`), и как
деинсталлятор с `--uninstall`.

Пересоздать скриншоты (выдуманные данные, ничего реального не читается и не пишется):

```powershell
Clipvault.exe --screenshots docs\screenshots
```
