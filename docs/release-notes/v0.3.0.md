## Clipvault 0.3.0 — преобразования, вставка без форматирования, сниппеты

- **Вставка без форматирования** по `Ctrl+Shift+V` (сочетание настраивается): вставляется только текст из буфера, а прежнее содержимое буфера (со всеми форматами — HTML, RTF, картинки, файлы) возвращается после вставки; восстановление не попадает в историю. ⚠ Сочетание перехватывается глобально, а в части приложений (браузеры, Word, терминалы) `Ctrl+Shift+V` уже значит то же самое — если мешает, смените его в «Настройках».
- **Быстрые преобразования** — меню «Преобразовать» у выбранной записи (результат вставляется в окно, из которого открыт список) и горячие клавиши: формат и минификация JSON (`serde_json`, ошибка со строкой и столбцом, порядок ключей сохраняется), Base64 (кодировать/декодировать), URL (процентное кодирование UTF-8), смена раскладки EN↔RU в обе стороны (`ghbdtn` ↔ `привет`, режим «авто» выбирает направление по буквам), извлечение всех ссылок и e-mail без повторов, регистр (ВЕРХНИЙ, нижний, Каждое Слово), обрезка пробелов, сортировка и уникализация строк. По умолчанию назначены `Ctrl+Alt+J` (формат JSON) и `Ctrl+Alt+L` (раскладка, авто); свои — в «Настройках». При ошибке ничего не вставляется, показывается уведомление.
- **Сниппеты:** папки и теги, ключевое слово, сочетание клавиш и плейсхолдеры `{date}`, `{time}`, `{clipboard}`. Вставка — по сочетанию, из вкладки «Сниппеты» или по ключевому слову (наберите его в поиске истории и нажмите `Enter`). Во вкладке «Сниппеты» ниже виден список закреплённых записей. Сниппеты лежат в том же зашифрованном хранилище; очистка истории их не удаляет.
- `clipvault-cli transform <имя>` (stdin → stdout, `--list` — список имён) работает без доступа к хранилищу; `list`, `search`, `get`, `purge` — как раньше.

## Файлы релиза

| Файл | Что это |
| --- | --- |
| `Clipvault-Setup.exe` | установщик: ставит в `%LOCALAPPDATA%\Programs\Clipvault`, права администратора не нужны |
| `Clipvault.exe` | переносная версия (тот же файл); её же скачивает автообновление |
| `clipvault-cli.exe` | консольная версия: `list`, `search`, `get`, `transform`, `purge` |
| `SHA256SUMS.txt` | контрольные суммы |

## Что важно знать

- **Обновление с 0.2.0:** кнопка «Обновить» в окне или `Clipvault.exe --update`; история, сниппеты и ключ остаются на месте.
- **SmartScreen.** Исполняемые файлы **не подписаны**: Windows может показать «неизвестный издатель». Сверяйте `SHA256SUMS.txt`.
- **Приватность.** Никакой синхронизации, облака и телеметрии; единственный сетевой запрос — проверка новой версии (отключается). Тексты преобразований и сниппетов в журнал не пишутся: в журнале только имя действия.
- Горячие клавиши — через `RegisterHotKey` (глобального хука клавиатуры нет); если сочетание занято другой программой, Clipvault покажет уведомление.

## Ограничения

- Преобразования и их ошибки — таблицы модульных тестов (в обе стороны для раскладки, круговые для JSON/Base64/URL), сниппеты и плейсхолдеры — модульные тесты хранилища и подстановки.
- Вставка по горячим клавишам, вставка без форматирования и восстановление буфера проверены сценарием `scripts/e2e.ps1` на чистой Windows-машине GitHub Actions; **на настоящей рабочей машине с живым пользователем эти сценарии не гонялись** (они нажимают клавиши и занимают фокус). Вставка сниппета по сочетанию использует тот же код, что и вставка преобразования, но отдельно автоматически не проверялась (сниппеты создаются только в окне).
- Восстановление буфера возвращает форматы, лежащие в памяти (текст, HTML, RTF, картинки в DIB/PNG, список файлов); данные в форме GDI-дескрипторов (метафайлы, палитры) не восстанавливаются.
- Вставка в окна, запущенные от администратора, по-прежнему возможна только через отдельное окно `--admin` (UIPI); с настоящим запросом UAC оно не проверялось.
- Из текста сниппета нельзя вставить символ `{`, непосредственно за которым идёт `date}`, `time}` или `clipboard}` без раскрытия (экранирования нет).
- Подробнее — в [README](https://github.com/ahsoggg-creator/clipvault#readme).
