## Clipvault 0.3.2 — компактное окно быстрой вставки, нормальное перетаскивание, запись сочетаний

- **Компактное окно, как `Win+V`.** По сочетанию (и по `Win+V`, если включён режим Clipvault) открывается узкое окно 380×540: **один клик по записи вставляет её сразу**. Полное окно — из трея или кнопкой в шапке; в «Настройках» режим переключается.
- **Фишки.** `Ctrl+клик` — выбрать несколько записей и вставить их построчно; `Shift+клик` / `Shift+Enter` — вставить как простой текст; при наведении — кнопки «закрепить»/«удалить» и всплывающий предпросмотр (текст, картинка, файлы, цвет); в меню правой кнопки — «Преобразовать» и «Вставить как текст»; в компактном окне фильтры только по типам, которые есть в истории.
- **Окно перетаскивается между мониторами.** Раньше его двигала штатная функция системы, которой нужен фокус окна. Теперь окно следует за курсором, а тянуть можно за всю верхнюю полосу.
- **Сочетания клавиш записываются нажатием.** Старая запись не могла поймать даже `Ctrl+Alt+V` (egui превращает `Ctrl+V` в событие вставки и не видит Win), а занятое сочетание срабатывало само. Теперь запись читает физическую клавиатуру, на время записи глобальные хоткеи снимаются. `Esc` — отмена, `Backspace` — очистить. Работает для окна, вставки без форматирования, преобразований, сниппетов и окна администратора.
- Окно открывается на мониторе, где находится мышь, с учётом его масштаба.

## Файлы релиза

| Файл | Что это |
| --- | --- |
| `Clipvault-Setup.exe` | установщик: ставит в `%LOCALAPPDATA%\Programs\Clipvault`, права администратора не нужны |
| `Clipvault.exe` | переносная версия (тот же файл); её же скачивает автообновление |
| `clipvault-cli.exe` | консольная версия: `list`, `search`, `get`, `transform`, `purge` |
| `SHA256SUMS.txt` | контрольные суммы |

## Что важно знать

- **Обновление с 0.3.1:** кнопка «Обновить» в окне или `Clipvault.exe --update`; история, сниппеты и ключ остаются на месте.
- **SmartScreen.** Исполняемые файлы **не подписаны**; сверяйте `SHA256SUMS.txt`.

## Ограничения

- Модульные тесты, `clippy` и сборка проходят. Перетаскивание между мониторами, запись сочетаний, размеры и поведение компактного окна, а также `Win+V` после перезапуска проводника **на живом рабочем столе не проверялись**.
