## Clipvault 0.3.1 — Win+V, нормальные кнопки окна

- **Кнопки окна нажимаются.** Полоса перетаскивания перекрывала кнопки шапки — клики до них не доходили. Теперь кнопки лежат поверх неё.
- **«—» и «×» в шапке:** «—» сворачивает окно в трей, «×» закрывает приложение целиком (раньше «×» только прятал окно; выйти можно и через меню трея).
- **Быстрая вставка по Win+V.** В «Настройках» переключатель «Windows (стандартная) / Clipvault». Выбор Clipvault записывает `DisabledHotkeys=V` в `HKCU\...\Explorer\Advanced` и регистрирует Win+V через `RegisterHotKey` — клавиатурного хука по-прежнему нет. Чтобы переключение вступило в силу, нужно перезапустить проводник (кнопка в настройках; панель задач моргнёт на секунду). Обратный выбор и удаление программы возвращают Win+V Windows. ⚠ Пока Clipvault не запущен, Win+V не делает ничего — держите автозапуск включённым.
- **Окно у курсора мыши** — необязательная настройка: окно открывается рядом с курсором, а не по центру экрана.

## Файлы релиза

| Файл | Что это |
| --- | --- |
| `Clipvault-Setup.exe` | установщик: ставит в `%LOCALAPPDATA%\Programs\Clipvault`, права администратора не нужны |
| `Clipvault.exe` | переносная версия (тот же файл); её же скачивает автообновление |
| `clipvault-cli.exe` | консольная версия: `list`, `search`, `get`, `transform`, `purge` |
| `SHA256SUMS.txt` | контрольные суммы |

## Что важно знать

- **Обновление с 0.3.0:** кнопка «Обновить» в окне или `Clipvault.exe --update`; история, сниппеты и ключ остаются на месте.
- **SmartScreen.** Исполняемые файлы **не подписаны**; сверяйте `SHA256SUMS.txt`.

## Ограничения

- Модульные тесты проходят (в том числе правка списка `DisabledHotkeys`). Клики по кнопкам, перетаскивание, Win+V после перезапуска проводника и позиция окна у курсора **на живом рабочем столе не проверялись**.
