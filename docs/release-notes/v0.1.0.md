## Clipvault 0.1.0 — история буфера, зашифрованное хранилище, мгновенный поиск

Первый выпуск: менеджер буфера обмена для Windows, который хранит всё в зашифрованном виде.

- **История.** Clipvault слушает буфер через `AddClipboardFormatListener` (без хука клавиатуры) и запоминает текст, форматированный текст (HTML/RTF), изображения, списки файлов (`CF_HDROP`), цвета (`#HEX`, `rgb()`, `hsl()` — в окне с цветным превью и пересчётом в другие форматы), ссылки и пути. У каждой записи есть источник (программа и заголовок окна) и время.
- **Шифрование на диске.** В `%APPDATA%\Clipvault` нет ни одного открытого фрагмента содержимого: записи, метаданные и картинки лежат в журнале из кадров XChaCha20-Poly1305. Свой формат вместо SQLite — значит нет ни WAL, ни временных файлов с открытым текстом, ни поискового индекса на диске: индекс строится в памяти при запуске. Ключ — 32 случайных байта, обёрнутые DPAPI (`CryptProtectData`) для вашей учётной записи Windows. Модель угроз (от чего защищает и от чего нет) — в [README](https://github.com/ahsoggg-creator/clipvault#приватность-и-модель-угроз).
- **Дедупликация.** BLAKE3 от нормализованного содержимого (переводы строк, пробелы по краям): повтор поднимает запись наверх и увеличивает счётчик, а не создаёт копию.
- **Всплывающее окно** по `Ctrl+Alt+V` (настраивается; `Win+V` зарезервировано Windows): нечёткий поиск по мере ввода, фильтры по типу, приложению и дате, предпросмотр (текст, картинка, цвет, список файлов), вставка клавишей `Enter` или цифрой `1–9`, закрепление (`Ctrl+P`), удаление (`Ctrl+D`), «Очистить всё» (с выбором: оставить ли закреплённые). Окно закрывается по `Esc` и при потере фокуса.
- **Лимиты и режимы.** Размер записи, срок хранения и число записей; пауза записи и «режим инкогнито» — в окне и в меню значка в трее.
- **Вставка в окна администратора.** Windows (UIPI) не даёт обычной программе слать клавиши окнам с повышенными правами: Clipvault говорит об этом понятным текстом. Для таких окон — отдельная копия `Clipvault.exe --admin` (один запрос UAC из «Настроек»), у неё своё сочетание `Ctrl+Alt+Shift+V`; она только вставляет и ничего не записывает, основная копия остаётся без повышения.
- **Установщик** без прав администратора: `Clipvault-Setup.exe` (или `--install`) ставит в `%LOCALAPPDATA%\Programs\Clipvault`, добавляет ярлык в «Пуск» и запись в «Приложения и возможности»; `--uninstall` убирает всё (историю — по отдельной галочке).
- **Автообновление.** Раз в сутки запрос к `api.github.com`; в окне появляется кнопка «Обновить»: скачивание `Clipvault.exe`, проверка SHA-256 по `SHA256SUMS.txt`, замена файла и перезапуск. `Clipvault.exe --update` делает то же без окна; отключается в «Настройках».
- **Диагностика.** Журнал `%APPDATA%\Clipvault\logs\clipvault.log` (ротация 512 КБ) и отчёты о сбое `logs\crashes\crash-<время>.txt`. В них нет содержимого буфера: только типы и счётчики; текст самой паники в отчёт сознательно не попадает.
- **Демо и скриншоты:** `Clipvault.exe --demo` (выдуманные записи, ничего не читается и не пишется), `Clipvault.exe --screenshots <папка>`. Интерфейс — русский и английский (переключатель в «Настройках»).
- `clipvault-cli`: `list`, `search`, `get <id>`, `purge`.

## Файлы релиза

| Файл | Что это |
| --- | --- |
| `Clipvault-Setup.exe` | установщик: ставит в `%LOCALAPPDATA%\Programs\Clipvault`, права администратора не нужны |
| `Clipvault.exe` | переносная версия (тот же файл; установить можно из «Настроек»); её же скачивает автообновление |
| `clipvault-cli.exe` | консольная версия: `list`, `search`, `get`, `purge` |
| `SHA256SUMS.txt` | контрольные суммы |

## Что важно знать

- **Права администратора** основной копии не нужны. Они нужны только чтобы вставлять в окна, запущенные от администратора, — для этого отдельное окно `--admin` (один запрос UAC).
- **Windows 11.** Сочетание `Win+V` занято системой, поэтому окно вызывается `Ctrl+Alt+V`. Значок трея может оказаться в скрытой области («^» рядом с часами).
- **SmartScreen.** Исполняемые файлы **не подписаны**: Windows может показать «неизвестный издатель». Сверяйте `SHA256SUMS.txt`.
- **Приватность.** Никакой синхронизации, облака и телеметрии. Единственный сетевой запрос — проверка новой версии на GitHub (отключается).

## Ограничения

- Проверено на реальной системе (Windows 11, `scripts/e2e.ps1`): запись текста, ссылок, цвета и картинки из буфера, дедупликация, отсутствие открытого текста в файлах данных и журнале, открытие окна по сочетанию, вставка клавишей `Enter` в чужое окно, второе окно `--admin` (без повышения), установка/удаление без администратора.
- **Не проверено на реальной системе:** вставка в окно, запущенное от администратора, через `--admin` с настоящим повышением (UAC); списки файлов (`CF_HDROP`) и форматированный текст (HTML/RTF) при вставке в чужие приложения; запуск при входе в Windows; автообновление на настоящем релизе (первый релиз — обновляться пока не на что).
- Сочетание `Ctrl+Alt+V` может быть занято другой программой — тогда Clipvault покажет уведомление; выберите другое в «Настройках».
- Нет хранимого поискового индекса: при очень большой истории (сотни тысяч записей) запуск медленнее — индекс собирается в памяти (измерения — в [docs/BENCHMARKS.md](https://github.com/ahsoggg-creator/clipvault/blob/master/docs/BENCHMARKS.md)).
- Удалённые записи физически исчезают из файла при его пересборке (делается сразу при удалении и «Очистить всё»); следы шифртекста на SSD (износ-выравнивание) без ключа бесполезны, но стереть их программа не может.
- Подробнее — в [README](https://github.com/ahsoggg-creator/clipvault#readme).
