# Измерения

Здесь — только то, что реально измерено, с методикой. Других чисел о скорости в README нет.

## Методика

`cargo run --release -p clipvault-core --example bench -- 50000` (код — `crates/core/examples/bench.rs`).

- Данные — синтетические: 50 000 записей по 6–36 слов из словаря в 24 слова плюс случайные числа,
  детерминированный генератор. Реальные данные пользователя не используются.
- Все замеры — в одном процессе, сборка `release` (`lto = "thin"`).
- Поиск: медиана 15 повторов одного запроса по всей истории (нечёткий поиск, все записи, без фильтров);
  в замер входят сортировка и сбор результата.
- Запись в зашифрованное хранилище: 2 000 записей, каждая — отдельный кадр XChaCha20-Poly1305 + `fsync`
  (так пишет приложение). Старт — повторное открытие этого хранилища: расшифровка кадров и сборка индекса.

## Машина

AMD Ryzen 5 7500F (6 ядер), 16 ГБ ОЗУ, SSD, Windows 11. Одна машина, один прогон: цифры показывают порядок
величин, а не гарантии.
